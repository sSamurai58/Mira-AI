# Внимание и фокус

Главный тезис: внимание — это навык, а не черта характера.

Практика коротких интервалов укрепляет концентрацию.
Формула: намерение → действие → короткая пауза.
Мы учимся возвращать ум мягко, без самокритики.

Устойчивая фраза: «мягко верни внимание».
Логика материала: наблюдение → выбор якоря → повтор цикла.
