Mira — куда смотреть после установки
====================================

Папка, где лежит Mira.exe (Program Files / AppData\Local\Programs\Mira), —
это ДВИЖОК приложения (Electron + Chromium).

Там нормально видеть кучу .dll / .pak / locales — это не «мусор» и не
библиотека материалов Mira. Без них программа не запустится.

Где лежат ВАШИ данные (библиотека, скиллы, память, .env):
  %APPDATA%\Mira\

Типичное дерево:
  %APPDATA%\Mira\
    .env                 — ключи API (не в git)
    data\
      skills\            — ваши скиллы
      protocols\         — протоколы
      screenshots\       — снимки экрана
      backups\           — резервные копии
      logs\              — логи / Doctor
    mira\
      library\           — загруженные книги/файлы (библиотека)
      library\database\  — SQLite

Стартовые примеры (skills/seed) лежат внутри установки:
  …\Mira\resources\seed\

Открыть папки удобнее из приложения:
  Настройки → Данные и приватность → «Где лежат данные»

Не удаляйте dll рядом с Mira.exe — сломаете запуск.
Не ищите «библиотеку» в папке с exe — она в %APPDATA%\Mira.
