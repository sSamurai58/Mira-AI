Mira на macOS — куда смотреть после установки
=============================================

Файл Mira-*.dmg / папка Mira.app — это ДВИЖОК (Electron + Chromium).
Внутри .app много служебных файлов — это не «мусор» и не ваша библиотека.

Где лежат ВАШИ данные (библиотека, скиллы, память, .env):
  ~/Library/Application Support/Mira/

Типичное дерево:
  ~/Library/Application Support/Mira/
    .env
    data/
      skills/
      protocols/
      screenshots/
      backups/
      logs/
    mira/
      library/

Первый запуск (неподписанная сборка из GitHub Releases):
  1) Откройте DMG, перетащите Mira в «Программы».
  2) Если Gatekeeper ругается: ПКМ по Mira → «Открыть» → «Открыть».
  3) Для контроля экрана (клик/ввод): Системные настройки →
     Конфиденциальность и безопасность → Универсальный доступ → включите Mira.
  4) Для снимков экрана: … → Запись экрана → разрешите Mira.
  5) Опционально: brew install cliclick — точнее клики/ввод.

Терминал внутри Mira на Mac по умолчанию: /bin/zsh
(или ваш $SHELL / TERMINAL_SHELL).

Не удаляйте Frameworks внутри Mira.app — сломаете запуск.
