Mira на macOS — куда смотреть после установки
=============================================

Файл Mira-*.dmg / папка Mira.app — это ДВИЖОК (Electron + Chromium).
Внутри .app много служебных файлов — это не «мусор» и не ваша библиотека.

Где лежат ВАШИ данные (библиотека, скиллы, память, .env):
  ~/Library/Application Support/Mira/

Типичное дерево:
  ~/Library/Application Support/Mira/
    .env
    data/
      skills/
      protocols/
      screenshots/
      backups/
      logs/
      dictation/
    mira/
      library/

Первый запуск (сборка из GitHub Releases пока БЕЗ подписи Apple)
----------------------------------------------------------------
Окно «Файл «Mira» не был открыт» / «Apple не удалось подтвердить…»
с кнопками «Переместить в Корзину» и «Готово» — это Gatekeeper.
НЕ нажимайте «Переместить в Корзину».

Способ A (предпочтительный на новых macOS):
  1) В диалоге нажмите «Готово» (не Корзину).
  2) Системные настройки → Конфиденциальность и безопасность.
  3) Пролистайте вниз до блока про заблокированное приложение Mira.
  4) Нажмите «Всё равно открыть» / Open Anyway → подтвердите паролем.
  5) При повторном запросе выберите «Открыть».

Способ B (Finder):
  1) Откройте DMG, перетащите Mira в «Программы».
  2) ПКМ (Control+клик) по Mira.app → «Открыть» → «Открыть».
     Обычный двойной клик снова покажет блок — нужен именно ПКМ → Открыть.

Способ C (Терминал, если A/B не помогли):
  xattr -cr "/Applications/Mira.app"
  затем снова ПКМ → «Открыть».

После первого успешного запуска предупреждение обычно больше не появляется.

Права macOS для Mira
--------------------
  • Контроль экрана (клик/ввод): Конфиденциальность → Универсальный доступ → Mira.
  • Снимки экрана: … → Запись экрана → Mira.
  • Опционально: brew install cliclick — точнее клики/ввод.

Терминал внутри Mira на Mac по умолчанию: /bin/zsh
(или ваш $SHELL / TERMINAL_SHELL).

Не удаляйте Frameworks внутри Mira.app — сломаете запуск.

Почему так: пока нет Apple Developer ID / notarization. Когда подпись
подключат, это окно исчезнет. Сборка при этом нормальная — блокирует macOS,
а не «сломанный» файл.

Подпись / нотаризация (для релиза без Gatekeeper)
-------------------------------------------------
Нужны секреты на машине сборки / в CI:
  CSC_LINK + CSC_KEY_PASSWORD  (Developer ID Application .p12)
  APPLE_ID + APPLE_APP_SPECIFIC_PASSWORD + APPLE_TEAM_ID  (notarize)
В electron-builder.yml сейчас identity: null — без сертификата подписать нельзя.
Без них остаётся способ A/B/C выше.

Метрики «Ресурсы» на Mac
------------------------
ОЗУ считается через vm_stat (как Activity Monitor: free+inactive+purgeable),
а не через os.freemem() — иначе кольцо почти всегда «100%».
GPU/VRAM — через IOKit (IOAccelerator); на Apple Silicon VRAM = unified memory.
