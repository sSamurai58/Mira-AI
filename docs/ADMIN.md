# Администрирование — план (discovery)

**Статус:** v1 **реализован** (UI + локальный store ключей/пользователей; роли-заглушка).  
**Старт discovery:** 2026-11-16.  
**Обновлено:** 2026-11-17 (код).

## Цель направления

Контур **администрирования** — ядро продукта (Mira во многом и есть админка): владелец управляет пользователями, ключами и доступом. Реализацию начинаем только после явного OK; сейчас — только docs.

## Каркас

```
Администрирование          ← корневой раздел (перед Настройками); только владелец; Win v1
├── Пользователи
│   ├── Статистика         ← полная сводка / использование / уровни Миры
│   ├── Информация         ← карточки, ключ, срок, устройства, сортировка, макс. функционал
│   └── Ключи и доступ     ← создание и редактирование ключей
└── Роли                   ← discovery ещё не начат (`— — —`)
```

## 2. Пользователи

### 2.1 Статистика — в плане (не реализуем пока)

| Что | Требование |
|-----|------------|
| Сводка | **Полная сводка** по пользователям / доступу |
| Использование | **Максимальная статистика по использованию** Mira |
| Уровни | **Уровни Миры** (рост / уровень ядра в статистике) |

Детализация метрик, периодов и UI (графики vs цифры) — при старте реализации или отдельном уточнении; направление: максимум видимости использования.

### 2.2 Информация — в плане (не реализуем пока)

| Что | Требование |
|-----|------------|
| Состав | **Вся информация по пользователям** |
| На карточке (минимум из диктовки) | ключ · срок ключа · кол-во устройств · карточка пользователя |
| Список | **Сортировка** |
| Объём | **Максимум функционала** по работе с информацией о пользователях (CRUD/фильтры/действия — уточнять при реализации, ориентир: полный админский контур, не урезанный stub) |

### 2.3 Ключи и доступ — в плане (не реализуем пока)

**Создание ключа**

| Параметр | Есть |
|----------|------|
| Срок действия ключа | да |
| Кол-во устройств | да |

**Редактирование ключей**

| Действие | Есть |
|----------|------|
| Продление срока использования | да |
