# Администрирование — план (discovery)

**Статус:** сбор требований. **Реализации нет** — только разговор и фиксация в docs.  
**Старт discovery:** 2026-11-16.  
**Порядок:** идём по пунктам сверху вниз; внутри пункта — по подразделам. Функционал каждого подраздела разбираем отдельно, когда до него доходим.

## Цель направления

Контур **администрирования** — ядро продукта (приложение во многом и есть админка): владелец управляет доступом к Mira. Доступ в перспективе — **по ключам** из админки; лимит устройств уточняется в подразделе «Ключи и доступ».

## Каркас плана

```
Администрирование          ← корневой раздел (перед Настройками)
├── Пользователи
│   ├── Статистика
│   ├── Информация
│   └── Ключи и доступ
└── Роли                   ← после закрытия «Пользователи»
```
