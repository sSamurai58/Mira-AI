# DESIGN

Тёмный UI голосового ИИ-помощника Mira: блоки, токены, состояния, экраны, stubs.  
Источник правды по интерфейсу (см. `RULES.md`).

## Направление

- Тема по умолчанию: **тёмная**.
- Первый viewport — **один смысл**: состояние ассистента + диалог + кнопка говорить.
- Без дашборд-каши: провайдер, экран, браузер — в настройках / по запросу, не в герое.
- Крупная типографика для статуса («Слушаю…») и текста реплик.
- Подтверждение опасных действий экрана/браузера и **отправки в мессенджеры** — модально, ясно, без мелкого текста (превью текста, чат, платформа).
- Карточки только для сущностей/действий, не для декора.

## Состояния голоса (MVP)

| Состояние | UI | Поведение |
|-----------|-----|-----------|
| `idle` | «Готово» + CTA говорить | Ждём пользователя |
| `listening` | Пульс/индикатор уровня | Идёт запись с микрофона |
| `thinking` | Спокойный индикатор | ASR/диалог обрабатывают |
| `speaking` | Индикатор озвучки + текст ответа | TTS играет; доступна отмена |
| `error` | Сообщение + retry | Микрофон / ASR / TTS сбой |

Движение (минимум):

1. Переходы состояний — короткий crossfade (~150–200 ms).
2. `listening` — лёгкая пульсация индикатора (не glow-фейерверк).
3. Press на PTT / ошибка toast — понятный press/fade.

## Stubs

- Пока нет ASR/TTS: PTT показывает `StubBadge` и toast «скоро», либо mock-пайплайн только в dev-флаге.
