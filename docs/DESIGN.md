# DESIGN

Тёмный UI голосового ИИ-помощника Mira.  
Источник правды по интерфейсу (см. `RULES.md`).

## Agent skills для дизайна и анимации

При проектировании/реализации UI и motion агент подключает **только нужные** скиллы из `.cursor/skills/` (upstream: [emilkowalski/skills](https://github.com/emilkowalski/skills/tree/main/skills)). Это **не** продуктовый каталог PRD #9.

## Принципы UX/UI (жёсткие)

1. **Одна главная задача на home** — диалог с Mira. Не витрина всех фич.
2. **Мало пунктов в корневой навигации** — максимум **4** (desktop: бок; mobile: низ). Всё остальное — **внутри** разделов или в **Настройках**.
3. **Настройки ≠ фичи.** Ключи API, разрешения, пути, аккаунты мессенджеров — только в Настройках / Интеграциях, не табами на главной.
4. **Студии и каталоги** — рабочие зоны второго уровня (не отдельный таб на каждый инструмент).
5. **Новая фича из PRD** → сначала решить: home / рабочая зона / настройки / модалка. **Запрещено** добавлять 5-й+ корневой таб без записи в MEMORY и правки этой таблицы.
6. Карточки — только для сущностей/действий; без декоративного «дашборда».
7. Опасные действия (экран, браузер, мессенджеры, терминал, wipe данных) — **модальное превью + confirm**; политика режимов — F12 (`always` по умолчанию до реализации).

## Информационная архитектура

```
Mira
├── 1. Диалог          ← HOME (единственный «герой»)
├── 2. Память          ← прошлое: чаты + выученное
├── 3. Мастерская      ← skills, протоколы, голоса/студия, библиотека, терминал
└── 4. Настройки
         ├── Внешний вид       ← выбор темы (THEMES.md)
         ├── Общие
         ├── Голос и аудио
         ├── API и модели
         ├── Интеграции
         ├── Терминал          ← shell, шрифт (не эмулятор целиком)
         └── Данные и приватность
```

Корневых пунктов **ровно четыре**. Blender, Telegram, Studio, Library, Terminal — **не** корневые табы.

## Корневая навигация (4 пункта)

| Ключ | Подпись | Назначение |
|------|---------|------------|
| `chat` | Диалог | Home: состояние голоса, PTT, лента диалога, быстрый голос/модель |
| `memory` | Память | Сессии, поиск «о чём говорили», выученные единицы (#14) |
| `workshop` | Мастерская | Хаб: Скиллы · Протоколы · Голоса · Библиотека · **Терминал** |
| `settings` | Настройки | Общие · Голос · API · Интеграции · Данные |

Внутри **Мастерская** — **сегменты / боковое меню раздела** (не новые корневые табы):

| Сегмент | Содержание |
|---------|------------|
| `skills` | Каталог, импорт, «активен сейчас» vs установлен |
| `protocols` | Панель протоколов: md + CRUD + Run |
| `voices` | Каталог голосов, превью, выбрать активный → вход в **Студию** |
| `library` | Материалы #14: upload, статусы разбора, план, propose skill |
| `terminal` | Полноценный встроенный терминал (#16): сессии, cwd, интерактив |

В **Память** позже: сегмент `notes` (F6). Blender, мессенджеры, почта (F4), медиа (F7) — **не** сегменты Мастерской по умолчанию: интеграции / tools из Диалога.

**Split из Диалога (опц.):** кнопка «Терминал» открывает нижнюю/боковую панель того же эмулятора — без смены корневого раздела. Не дублировать второй «терминальный» продукт.

## Home — Диалог

Только:

- статус (`idle` / `listening` / `thinking` / `speaking` / `error`);
- лента текущего диалога;
- PTT / поле текста;
- компактные чипы: **активный голос**, **активная модель** (тап → поповер выбора, не отдельный экран);
- при активном tool: тонкий badge («Blender», «экран», skill name) — без панели инструментов на весь экран.

**Не на home:** список интеграций, формы API-ключей, загрузка книг, студия фраз, полный каталог skills, полноэкранный терминал (только опц. split-панель).

## Память

Два подрежима (переключатель внутри раздела, не корень):

1. **Разговоры** — сессии, поиск по истории (#3).  
2. **Выученное** — единицы из #14 (фразы, логика) со ссылкой на источник.

## Мастерская

Один экран-хаб с сегментами. Глубина: `Мастерская → Голоса → Студия (проект)` — нормально; `корень → Студия` — нет.

### Студия голоса (внутри Голоса)

Цикл UX (#15): Создать → фразы → загрузить → автообработка → ещё фраз.  
Не выносить шаги цикла отдельными табами приложения.

## Настройки — карта

| Раздел | Что внутри |
|--------|------------|
| **Внешний вид** | Сетка всех тем из § «Цветовые темы» ниже; default `deep-sea-neon`; акцент = `--accent` выбранной темы |
| **Общие** | Язык UI (F8); **профиль** активный (F10); **режим подтверждений** F12: `always` / `smart` / `dangerous-list` + редактор списка классов |
| **Голос и аудио** | Микрофон, вывод, чувствительность; **wake-word / hands-free** и barge-in (F9); ссылка в каталог голосов / Студию → Мастерская |
| **API и модели** | Провайдеры Claude / Gemini / GPT (#5); ключи через `.env` / безопасный ввод (scoped к профилю при F10); модель по умолчанию; тест соединения |
| **Интеграции** | Подразделы-аккордеон: **Экран** (разрешения #6–7), **Браузер** (#8), **Мессенджеры** (#12: TG/WA/IG аккаунты), **Blender** (#13: путь, статус), **Интернет** (политика #4) |
| **Терминал** | Shell по умолчанию, шрифт/размер, scrollback; цвета терминала — из активной темы |
| **Данные и приватность** | Путь SQLite, пути библиотеки/корпусов; **backup / export / import** (F11); **забыть** память / библиотеку / выученное (с confirm); **Doctor + логи** (F13) |

Правило: новый внешний сервис → строка в **Интеграции** или **API и модели**, не новый корневой таб.

## Состояния голоса

| Состояние | UI | Поведение |
|-----------|-----|-----------|
| `idle` | «Готово» + CTA | Ждём PTT; при F9 hands-free — ждём wake-word |
| `listening` | Пульс уровня | Запись |
| `thinking` | Спокойный индикатор | ASR / LLM / tools |
| `speaking` | Озвучка + текст; **Стоп / перебить** | TTS; barge-in (F9) → стоп → `listening` |
| `error` | Сообщение + retry (+ «Doctor» → F13) | Сбой mic/ASR/TTS/API/интеграций |

Движение: crossfade состояний ~150–200 ms; лёгкий пульс listening; press на PTT — без glow-фейерверков.

## Цветовые темы, палитры и акценты

Источник правды по UI-цветам — **этот раздел**. Расширенные токены по каждой теме также дублируются в [`THEMES.md`](./THEMES.md). Референсы картинок: `docs/themes/`.

### Правила

- Компоненты используют **только** CSS variables (`--bg`, `--accent`, …), не сырой hex.
- Пользователь выбирает тему в **Настройки → Внешний вид** (сетка пресетов).
- **`--accent`** зашит в тему (v1): CTA, активный пункт nav, PTT, ключевые статусы.
- Default-тема: **`deep-sea-neon`**.
