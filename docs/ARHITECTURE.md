# ARHITECTURE

Устройство Mira: один процесс, диалог через LLM, память, экран/браузер, человечная речь, SQLite.  
Имя файла намеренно `ARHITECTURE.md` (см. `RULES.md` / `MEMORY.md`).

## Принципы

1. **Один процесс** — UI, оркестрация, инструменты и речь в одном приложении.
2. **Один файл данных** — SQLite; путь из `DATABASE_PATH`.
3. **Сменные адаптеры** — LLM (Claude / Gemini / GPT…), ASR, TTS без lock-in.
4. **Инструменты по команде** — интернет, экран, браузер вызываются явно из диалога.
5. **Явные stubs** — незавершённое в `PRD.md` / `DESIGN.md`.
6. **Обязательный scope** — возможности 1–8 из `PRD.md`.

## Пайплайн (обязательный контур)

1. Ввод: голос (ASR) и/или текст.
2. Подъём памяти: поиск по прошлым разговорам → фрагменты в контекст.
3. LLM (выбранный провайдер) → ответ + tool-calls при необходимости.
4. Инструменты: интернет / видимость экрана / контроль UI / браузер.
5. Ответ пользователю текстом + **человечная** озвучка (TTS).
6. Сохранение реплик и метаданных tool-call в SQLite.

Опасные действия экрана/браузера — через подтверждение (политика в RULES/MEMORY).

## SQLite

| Таблица | Назначение |
|--------|------------|
| `sessions` | Сессии диалога |
| `utterances` | Реплики user/assistant + время |
| `memory_index` | Поиск по истории (FTS или аналог) |
| `providers` / settings | Выбранный LLM/TTS (без секретов) |
| `meta` | Версия схемы |

Секреты API — только `.env`, не в БД.

## Границы модулей

| Слой | Ответственность | Не делает |
|------|-----------------|-----------|
| `ui` | Состояния, transcript, подтверждения | Прямые вызовы API вендоров |
| `orchestrator` | Склейка диалога, tool-loop, речь | Схема БД |
| `llm` | Адаптеры Claude / Gemini / GPT… | Автоматизация ОС |
| `asr` / `tts` | Распознавание / человечная озвучка | Продуктовая память |
| `memory` | Запись и поиск разговоров | Клики по экрану |
| `tools.web` | Интернет-поиск / fetch | Секреты в логах |
| `tools.screen` | Capture + automation | Обход подтверждений |
| `tools.browser` | Вкладки, история, поиск по критериям | Хранение API-ключей |
| `store` | SQLite, миграции | Правила диалога |
| `config` | `.env`, выбор провайдеров | Секреты в UI/логах |
