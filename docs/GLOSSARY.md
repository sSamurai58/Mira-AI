# Glossary

## Экраны
- Дом — главная вкладка с ядром Mira и правым rail
- Диалог — чат с пузырями и композером
- Мастерская — каталоги skills/protocols/paths и панели
- Настройки — API, голос, обновления, внешний вид
- Администрирование — корневой раздел (перед Настройками): пользователи, роли; только владелец; см. `docs/ADMIN.md`
- Update HUD — плавающий тост прогресса обновления
- Окно обновления — «Мира обновляется» во время NSIS replace

## Сущности
- Mira — голосовой ИИ-помощник (этот продукт)
- Пользователи (админ) — подраздел Администрирования: Статистика · Информация · Ключи и доступ (`docs/ADMIN.md`)
- Статистика (админ) — полная сводка, использование, уровни Миры
- Информация (админ) — карточки пользователей: ключ, срок, устройства, сортировка
- Ключи и доступ — создание/редактирование ключей (срок, лимит устройств)
- Роль (админ-контур) — TBD; список ролей пока не зафиксирован
- skill (runtime) — md/папка SKILL.md в каталоге приложения (PRD #9)
- product-team — Cursor-пакет ролей разработки в `.cursor/skills/product-team`
- develop / main — ветки: разработка / только релиз

## Ошибки
- broken-shortcut — Windows «ярлык больше не работает» при клике во время update
- update-no-relaunch — тихая установка без `--force-run`, приложение не открывается
