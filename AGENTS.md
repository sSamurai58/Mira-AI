# AGENTS

## Design & animation (on-demand)

For Mira UI, motion, and visual polish, load skills from `.cursor/skills/` (vendored from [emilkowalski/skills](https://github.com/emilkowalski/skills) — design/animation subset only).

- Start with `emil-design-eng` for overall taste.
- Use `animate`, `choreograph`, `gestures`, `animation-performance`, `review-animations`, etc. only when the task needs them.
- Do **not** load the whole set into every turn.
- Product user-skills (PRD #9) are separate from these agent skills.

See `.cursor/skills/README.md` and `docs/DESIGN.md` § Agent skills.
