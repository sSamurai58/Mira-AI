# Mira AI — SVG logos (crystal family)

Vector versions of the selected style (#5 crystal) and lockups (#10 adapted).

| File | Variant |
|------|---------|
| `01-mira-crystal-mark.svg` | Crystal mark only |
| `02-mira-horizontal-light.svg` | Horizontal lockup on light |
| `03-mira-horizontal-dark.svg` | Horizontal lockup on dark |
| `04-mira-stacked.svg` | Stacked MIRA / AI |
| `05-mira-app-icon.svg` | Rounded Windows app icon |

Source of truth for branding exports. PNG previews can be regenerated with:

```bash
rsvg-convert -w 1000 01-mira-crystal-mark.svg -o 01-mira-crystal-mark.png
```
