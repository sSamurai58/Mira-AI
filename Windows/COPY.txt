Копии / артефакты для Windows-сборки Mira
========================================

Источник (корень репозитория)     →  Windows/
-----------------------------------------------
package.json (скрипт pack:windows)
electron-builder.yml (win target) → config/electron-builder.windows.yml
dist/ + dist-electron/            → упакованы внутрь Mira-Setup-*.exe
NSIS license / macros             → nsis/
Скрипт сборки                     → scripts/build-installer.mjs

Готовые файлы:
  Mira-Setup-0.0.1.exe     — установщик (NSIS, x64)
  Mira-Portable-0.0.1.exe  — portable .exe без инсталляции
  Mira-Launch.bat          — быстрый запуск portable / unpacked
  latest.yml               — метаданные electron-updater

Пересборка: из корня репозитория
  npm run pack:windows
